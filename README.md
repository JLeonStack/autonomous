# autonomous

Agent-driven repository for evaluating the Anturno factory pipeline.

## Usage

```python
from slugify import slugify

slugify("Hello, World!")  # -> "hello-world"
```

Non-alphanumeric and non-ASCII characters are treated as separators and
collapsed to a single hyphen; no transliteration (e.g. `é` to `e`) is
attempted.

Run the tests from the repository root:

```sh
python3 -m unittest
```
