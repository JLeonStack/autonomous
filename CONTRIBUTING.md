# Contributing

## Purpose
This is an agent-driven repository used to evaluate the Anturno factory pipeline.
Changes here are proposed by agents and by people, and reviewed by people, so
every change should be easy to read, easy to check and easy to revert.

## Proposing a change
- One purpose per change. State the scope up front, before making any edits.
- Keep the change as small as that purpose allows; leave unrelated cleanups out.
- Say what you deliberately left alone when a reader might expect it to change.

## Acceptance criteria and evidence
- List acceptance criteria a reviewer can confirm from the diff or the files.
- This repository has no automated test suite or CI, so verify changes yourself.
- Record the exact commands you ran and the output they produced as evidence.

## Pull requests
- One pull request per change, small enough to review in a single sitting.
- Describe the purpose, the scope and the verification evidence in the body.
- Keep the diff limited to the files the stated purpose needs.

## Merging
- A human approves and performs the merge. Agents do not merge their own work.
- If a merged change turns out to be wrong, the recovery path is reverting it.
